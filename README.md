# 🍕 Pizza Sales Analytics Dashboard

This project is a **sales performance dashboard** built to analyze **pizza sales trends, revenue, order behavior, and product performance** using interactive visualizations.

---

## 🎯 Dashboard Goals

* Monitor **daily, monthly & yearly sales**
* Identify **top-selling pizzas & categories**
* Track **order volume & revenue trends**
* Understand **customer purchase patterns**

---

## 📊 Key Dashboard Highlights

* ✅ Total Revenue, Orders & Quantity KPIs
* ✅ Category-wise & Size-wise Sales Analysis
* ✅ Time-Series Sales Trends
* ✅ Best & Worst Performing Products
* ✅ Interactive Filters for Date, Category & Size
